# 🏦 Simple Bank Account Manager – Java DSA Project

## 📌 About the Project
Simple Bank Account Manager is a console-based banking application developed using Java. It allows users to perform basic banking operations such as creating accounts, depositing money, withdrawing money, checking account balances, searching accounts, and sorting account details.

This project demonstrates the practical implementation of Java programming, Object-Oriented Programming (OOP), and Data Structures and Algorithms (DSA).

## ✨ Features
- Create a new bank account.
- Deposit money into an account.
- Withdraw money from an account.
- Check account balance.
- Search accounts using account number.
- Display all registered accounts.
- Sort accounts alphabetically by customer name.
- Menu-driven console interface.

   ```bash

   ```

2. Open the project folder in VS Code.

3. Open the Java source file:
   `BankAccountManager.java`

4. Compile the program:
   ```bash
   javac BankAccountManager.java
   ```

5. Run the program:
